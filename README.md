Hi, I'm Gabriel 👋

I work in a software architecture team, connecting business requirements with technical decisions, with a focus on reliability, maintainability and clear integration boundaries between services. My main expertise is backend, but I also have experience with mobile and frontend, which helps me see how customer-facing apps, backend services and payment processors work together, and how a decision in one layer ends up affecting the whole solution.

## Hi, I'm Gabriel 👋

I'm a Senior Software Engineer from Brazil, curious by nature and a technology lover. I've spent my career building Java backends for fintechs, and over time I've become especially interested in the place where software architecture meets the financial domain.

## What I do

I work in a software architecture team, where my job is to connect business requirements with technical decisions. My focus is on reliability, maintainability and clear integration boundaries between services. I believe software shouldn't only meet today's requirements, it should also be easy for the next engineer to understand and change.

My main expertise is backend development, but I also have experience with mobile and frontend. That wider view helps me understand how customer-facing apps, backend services and payment processors work together, and how a decision in one layer ends up affecting the whole solution.

## Domain

Most of my experience is in cards and payments: card products, payment processing, fraud prevention and chargeback workflows. Knowing the domain well makes a big difference when designing systems that handle money, because the edge cases are usually where the business rules live.

## How I work

I write Java every day, across the LTS releases from Java 8 to Java 25, mostly with Spring Boot, Spring Data JPA and Hibernate. I like microservices and event-driven architectures, with Apache Kafka and Amazon SQS for messaging, and I pay attention to resilience patterns like Circuit Breaker. I care about practical design, explicit responsibilities and automated testing, using JUnit, Mockito, Pact and TDD whenever it makes sense.

On the infrastructure side, I work with AWS, Docker and Kubernetes, and with databases such as MySQL, PostgreSQL, MongoDB and Redis.

## Always learning

I like to back my experience with study. I've taken Mastercard's chargeback training for issuers and acquirers, and I hold AWS credentials in architecture, networking and cloud fundamentals (AWS Knowledge: Architecting, AWS Knowledge: Networking Core, AWS Cloud Quest: Cloud Practitioner and AWS Cloud Practitioner Essentials). I've also completed training in Spring Native and GraalVM for Java microservices.
